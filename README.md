# Music Discovery

Локальное приложение для поиска незнакомых музыкальных релизов в выбранном жанре или среди всех жанров. Три режима: близко к вкусу, расширить вкус, удиви меня. Жанры задаются каталогом; хип-хоп — первый пилот, а не ограничение модели.

Локальный сайт: React/TypeScript, FastAPI, личные аккаунты, чат, коллекция и оценки.
Существующие ранжирование, SQLite-журнал, pipeline обучения и OpenRouter используются
повторно; Streamlit остаётся диагностическим интерфейсом. Каталог по умолчанию
объединяет MusicBrainz с историческими RYM/AOTY и содержит 45 643 релиза
и 463 жанра/поджанра. AOTY Vibe есть у 6 205 релизов; порядок меток
подтверждён у 53. Покрытие неполное, оценки звучания остаются субъективными.
Пользовательские оценки помогают персонализации; независимая оценка её
полезности на широкой аудитории пока не проводилась.

Инструкции для работы с Claude Code: [docs/claude-code.md](docs/claude-code.md).

## Запуск

Из каталога проекта, с установленным `uv`:

```bash
cd ~/Projects/hiphop-discovery
uv sync --locked
npm --prefix frontend ci
npm --prefix frontend run build
uv run discovery-web serve
```

Открой **http://127.0.0.1:8000**, зарегистрируй логин и пароль, выбери жанр и
любимых исполнителей. «Использовать мой стартовый вкус» заполняет черновик набором
Death Grips, Kendrick Lamar, Denzel Curry, JPEGMAFIA и Kanye West; примените
его кнопкой «Сохранить вкус и продолжить». Новые аккаунты начинают без этого набора и без старой истории.

Повторный запуск после установки: `uv run discovery-web serve`.
Большие снимки `data/unified/*/catalog.json` (до 160 МБ) хранятся в Git как
`catalog.json.gz`: `load_catalog` читает сжатую копию, если распакованного файла нет.
Чат и подборки по подтверждённым настройкам используют серверный `.env` и общий
лимит OpenRouter $0.01/сообщение, $0.10/сутки. Оценки и история работают без
вызовов модели.
История аккаунтов хранится в `runtime/web/`. Подробности, восстановление пароля
и импорт старой базы: [локальный сайт](docs/local-web.md).

Прежний диагностический интерфейс запускается отдельно:

```bash
uv run streamlit run src/discovery/ui/app.py
```

Открой адрес, который напечатает Streamlit (обычно `http://localhost:8501`). Ключ API для обычной работы не нужен. Приложение начинает с `data/unified/community-genres-v4/catalog.json`: 45 643 релиза и 463 узла жанров. AOTY Vibe собраны для 6 205 релизов: [покрытие, источники и воспроизведение импорта](docs/vibes-collection-round2.md). В меню также доступны исходный каталог MusicBrainz и учебный каталог из 336 явно вымышленных релизов для проверки механики разных жанров.

Выбери жанр и степень новизны, при необходимости настрой любимых исполнителей. Нажми «Найти музыку», открой ссылки и оцени прослушанное. «Послушать позже» не считается лайком. История сохраняется в `runtime/discovery.sqlite3`; учебная история — отдельно в `runtime/discovery-demo.sqlite3`.

Включены все пять любимых исполнителей. Сохранены прежние 520 MusicBrainz ID и датированные наблюдения; исторические оценки RYM/AOTY показываются отдельно, с исходными шкалами и неизвестной датой измерения. Они не доказывают текущую малоизвестность. Строгий режим поэтому может вернуть пустую выдачу. Нулевое число голосов не означает низкую музыкальную оценку. Исходный sample из 33 релизов сохранён отдельно.

В коллекции доступны поиск, фильтры и группировка. Удаление чатов и два режима
очистки коллекции описаны в [инструкции библиотеки](docs/library-management.md).

## CLI и проверки

[Проверки по твоим примерам](docs/evals/user-recommendations.md): три запроса из документа, отдельный отчёт с ответами и критериями. Проверка каталога бесплатна; реальный прогон включается только через `--live` и ограничен $0.01.

```bash
uv run discovery --db runtime/cli.sqlite3 recommend --genre hip-hop
uv run discovery --db runtime/discovery.sqlite3 metrics
uv run discovery --db runtime/discovery.sqlite3 export --output artifacts/history.json
uv run discovery --db runtime/discovery.sqlite3 backup --output artifacts/history-backup.sqlite3
uv run ruff check src tests
uv run python -m discovery.evals.run --suite release --offline --output artifacts/evals/release.json
uv run python -m discovery.evals.entity_matching --verify-source-root . --output artifacts/evals/entity-matching.json
```

Экспорт и backup не перезаписывают существующий файл. CLI-рекомендация сохраняет отдельное решение и показ; пример использует отдельную БД от UI. CLI без сохранённых предпочтений начинает без личного профиля.

## Добавленные данные

Совместный набор метаданных: `data/training/musicbrainz-wikidata-expanded/releases.jsonl` и соседний `manifest.json`. Он содержит 520 строк MusicBrainz и 10 точно сопоставленных записей Wikidata, из которых пять содержат дополнительные жанровые признаки. Это входные музыкальные данные для экспериментов, а не личные лайки/дизлайки. Personal training CLI принимает отдельно экспортированные оценки пользователя.

[Прямые ссылки на музыкальные площадки](docs/album-platforms-20261106.md): карточка собирает несколько площадок независимо и показывает все найденные страницы альбома.

[Расширение каталога и AOTY Vibe](docs/catalog-expansion-vibes.md): к прежним 9 903 релизам добавлено 35 732. Неоднозначные соответствия остаются вне выдачи; у 6 592 записей пока нет сопоставленного основного жанра. Только сопоставленные основные жанры определяют попадание в жанровую выдачу; вторичные метки сохраняются отдельно. [Прежний снимок](docs/unified-catalog.md) сохранён для воспроизводимости. [Проверка сопоставления](docs/entity-matching-eval.md) использует предварительную агентскую разметку 50 реальных пар и 6 искусственных ловушек; это не независимый человеческий gold и не оценка точности на всём каталоге.

[Отчёт о MusicBrainz и Wikidata](docs/data-update.md) содержит ограничения и команды воспроизведения. [Исходные RYM/AOTY](docs/community-data.md) сохранены в `data/community/` вместе с provenance. У неофициального AOTY API подтверждён один ответ из кеша; стабильность не подтверждена. [HTML-парсеры и CLI](docs/web-parsers.md) также доступны.

Работу сабагентов можно наблюдать в отдельном терминале:

```bash
python scripts/watch_agents.py
```

Панель показывает реальные события сессий и счётчики сборщика; `Ctrl+C` закрывает только просмотр.

## Обучение и эксперименты

```bash
uv run discovery --db runtime/discovery.sqlite3 export-training --output artifacts/training-records.json
uv run python -m discovery.training.train --config configs/supervised-unified.json --data artifacts/training-records.json --output artifacts/training/report.json
uv run python -m discovery.experiments.sequential_rl.evaluate --config configs/rl.json --output artifacts/rl/simulator.json
```

Без достаточных настоящих оценок обучение вернёт `insufficient_data`, не обученную личную модель. Для исторического экспорта есть `export-training --cutoff 2026-10-28T12:00:00+00:00`: исправления оценок фильтруются до выбора последней доступной оценки. В live-сервисе `as_of` относится к свежести наблюдений каталога, а не к историческому воспроизведению пользовательского профиля.

Новый конфиг относится к `community-taxonomy-v1+6e4b3bae01a2`; прежний `configs/supervised.json` сохранён для `mb-tags-v2`. Версии taxonomy/features в одном обучении не смешиваются. Для нового конфига нужны личные ответы на рекомендации нового каталога; общественные оценки RYM/AOTY не заменяют эти ответы. Старые решения и обратная связь сохраняются как отдельные снимки.

Текущий сайт использует признаки `genre-tags-v2-artist-frequency`; для текущей таксономии подготовлен `configs/supervised-genres-v4.json`. Старые конфиги выше относятся к историческим экспортам. Для текущего аккаунта используйте [цикл обучения](docs/autotraining.md): он выбирает текущую версию и явно сообщает об исключённых старых строках. [Исправление ориентира исполнителя](docs/evals/artist-frequency-fix-20261102.md).

Экспериментальный bandit включается в UI отдельно: исследует пятый слот, сохраняет кандидатов и вероятность выбора. RL работает в симуляторе; его reward не является доказательством пользы для человека. [Устройство обучения и экспериментов](docs/learning-pipeline.md).

## OpenRouter

Переменные перечислены в [.env.example](.env.example). UI и CLI автоматически читают `.env` в корне проекта; уже заданное окружение процесса имеет приоритет. Локально настроена GPT-5.6 Luna с лимитами $0.01 на запрос и $0.10 за сутки UTC. Шаблон сохраняет нулевые бюджеты до явного включения. 2026-10-30 GPT-5.6 Luna прошла проверки уточнения запроса, объяснения карточки, неподдерживаемых условий и исключения знакомых исполнителей; обычные тесты остаются offline. Тарифы, результаты и ограничения — в [настройке расходов](docs/openrouter-costs.md). `DISCOVERY_DOTENV=0` отключает загрузку файла. После изменения `.env` перезапусти приложение.

Для ограниченного агента есть отдельный read-only preview:

```bash
uv run discovery --db runtime/discovery.sqlite3 agent-preview --genre hip-hop --text 'Найди экспериментальный хип-хоп внутри выбранного жанра'
```

Агент имеет только четыре инструмента каталога, лимиты времени/шагов/стоимости и независимую проверку результата. Preview не записывает рекомендации и не проводит bandit sampling. При сетевом timeout резерв бюджета сохраняется, поскольку отсутствие ответа не доказывает отсутствие списания провайдером.

`DISCOVERY_MODEL_PATH` может указывать на JSON-артефакт, прошедший явное продвижение по независимой проверке. Неподтверждённые жанры используют baseline. Модели из pickle не загружаются.
