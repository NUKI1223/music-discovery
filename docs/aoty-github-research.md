# AOTY: реальный исторический снимок из GitHub

Для локального исследования скачан публичный файл [`albums_data_added_1955_2024.xlsx`](https://github.com/rheera/album-of-the-year-analysis/blob/2801018ed93594efe29e35b6fff7661795517717/albums_data_added_1955_2024.xlsx) из `rheera/album-of-the-year-analysis`. Размер — **852 443 байта**, извлечено **6 703 строки**, **6 702 уникальных AOTY URL**. Это реальные опубликованные данные, не синтетические fixtures. Никакие страницы AOTY, сторонние API или механизмы обхода при получении этого снимка не использовались; чужой код не запускался.

Файлы находятся в `artifacts/source-research/aoty/`:

- `upstream/albums_data_added_1955_2024.xlsx` — исходный workbook;
- `raw.jsonl` — строки с исходными именами колонок и значениями;
- `manifest.json` — происхождение, commit, даты публикации/получения, лицензия и SHA-256 каждого файла;
- `profile.json` — проверка структуры, пропусков и покрытия;
- `extract_xlsx.py`, `profile_snapshot.py` — собственные воспроизводимые офлайн-скрипты;
- `upstream/README.md`, `commit.json`, `file-commit.json` и `*.reference.py` — сохранённые свидетельства издателя. Reference-файлы прочитаны как текст, не исполнялись.

Снимок закреплён на commit `2801018ed93594efe29e35b6fff7661795517717`. Последний commit самого XLSX — `2971831e3ea9fbe04452684b84faf711cfeba51a`, **26 июня 2024, 19:53:39 UTC**. Это дата истории публикации файла, а не дата измерения рейтингов. `observed_at` и `source_collection_date` оставлены `null`; `retrieved_at` хранится отдельно. Точная дата сбора отсутствует.

## Поля и проверка

Сохранены `artist_name`, `album_name`, `release_date`, `genres`, `user_score`, `user_score_float`, `number_of_ratings`, `link_to_album`, `list_year` и дополнительные исходные колонки. Жанры в raw JSONL остаются строкой с Python list literal; ссылка AOTY — относительный путь. Извлечение не сопоставляет названия с MusicBrainz и не заменяет неизвестную дату релиза годом списка.

Все 6 703 значения `user_score_float` находятся в диапазоне 0–100; счётчики — неотрицательные целые. У 895 строк нет `release_date`, у 309 — жанров. Найдено 581 различное название жанра; 564 строки попали под исследовательский поиск `hip hop`/`rap` внутри названий жанров. Это диагностический подсчёт, не присвоение таксономии приложения.

В данных есть 9 строк Death Grips, 5 Kendrick Lamar, 8 Denzel Curry, 7 JPEGMAFIA и 9 Kanye West, включая совместные credits по подстроке. Один URL дублируется: Mount Kimbie — *The Sunset Violent*, с рангами 75 и 78; прочие значения этих двух строк совпадают. Raw-файл сохраняет обе строки для аудита.

## Семантика и ограничения

По [описанию издателя](https://github.com/rheera/album-of-the-year-analysis/blob/2801018ed93594efe29e35b6fff7661795517717/README.md) это лучшие пользовательские альбомы по годам, 1955–2024. Отбор по годовым чартам смещён к заметным и высоко оценённым релизам; полного покрытия малоизвестной музыки он не даёт.

Издатель называет `number_of_ratings` числом пользовательских оценок. Но [его parser](https://github.com/rheera/album-of-the-year-analysis/blob/2801018ed93594efe29e35b6fff7661795517717/scraping_functions.py) извлекает первый числовой токен `.scoreText`, не проверяя слово `ratings`/`reviews`. Исходных HTML в проверенном наборе нет. Поэтому метрики отмечены **`publisher_reported_unverified`**: точная семантика счётчика, одновременность пары score/count и способ усреднения независимо не подтверждены. Несовпадение дробного среднего с числом целочисленных голосов не доказывает конкретную формулу взвешивания. Эти значения нельзя использовать как проверенную текущую редкость.

Лицензия набора — **unknown**: GitHub API вернул `license: null`, применимый LICENSE в просмотренном дереве не найден. Публичный файл сохранён для явно запрошенного локального исследования; права на дальнейшее перераспространение не установлены. README сообщает об изменявшемся способе получения данных, который здесь не воспроизводился.

Оценки сообщества не являются личными предпочтениями пользователя. Ни обученная персональная модель, ни эффективность рекомендаций этим снимком не подтверждены.

## Повторение извлечения

Из корня проекта, с новым выходным файлом:

```bash
.venv/bin/python artifacts/source-research/aoty/extract_xlsx.py \
  --source artifacts/source-research/aoty/upstream/albums_data_added_1955_2024.xlsx \
  --output /tmp/aoty-replay.jsonl
.venv/bin/python artifacts/source-research/aoty/profile_snapshot.py
```

Используется стандартная библиотека Python; формулы и внешние ссылки Excel не исполняются. JSONL сохраняет пропуски как `null`, не создаёт персональных меток и не приписывает наблюдениям дату скачивания.
