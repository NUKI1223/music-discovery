# Компактные панели чата — 2026-11-03

Верхняя строка уменьшена до 56 px. Название чата, настройки подборки и
стрелка панели остаются доступными; на телефоне настройки показываются
иконкой с доступным названием. Фильтры, память, переходы между страницами
истории, обновление истории и справка убраны в раскрываемую панель.
По умолчанию она свёрнута, выбор сохраняется в браузере отдельно для каждого
аккаунта. Раскрытая панель имеет собственную прокрутку и предел 45% высоты
экрана, чтобы длинная память не вытесняла переписку.

Нижняя панель содержит поле сообщения и одну строку действий. Пустое поле —
одна строка; при вводе оно растёт до 96 px и затем прокручивается внутри.
Shift+Enter и Enter работают как раньше. На телефоне интерактивные кнопки
сохраняют высоту 44 px. «Подобрать без ИИ» сокращено визуально до «Без ИИ»,
а доступное название осталось полным. Подсказки и лимиты доступны в верхней
раскрываемой панели и через описание поля для вспомогательных технологий.

Скрытые элементы исключены из клавиатурной навигации; переключатель имеет
aria-expanded/aria-controls. Учитывается prefers-reduced-motion. Настройки
подборки и сообщения о применении фильтров доступны и при свёрнутой панели.
Прокрутка альбомов остаётся внутри переписки, верх и поле ввода не уезжают.

Проверки: TypeScript/Vite build; Playwright для фильтров, памяти, отправки,
ошибок сети и компактной компоновки на 1440, 375 и 320 px. Проверяется высота
панелей, отсутствие горизонтального переполнения, прокрутка карточек,
сворачивание клавиатурой, сохранение выбора после reload и высота поля ввода.

Серверная логика, каталог и история пользователя не изменялись. Изменение
доступно после обновления страницы: сервер обслуживает новую frontend-сборку.
Платные API не вызывались; браузерные тесты используют отдельную тестовую базу.

Итог: сборка успешна, 15/15 браузерных сценариев пройдены. Скриншоты:
`artifacts/ux/compact-chat-20261103/`. Новые JS/CSS проверены на работающем сайте.
