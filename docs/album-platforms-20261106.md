# Несколько музыкальных площадок для каждого релиза — 2026-11-06

Исправлен общий механизм карточек: успешный поиск Apple Music больше не
останавливает поиск Deezer и других площадок. Чат и коллекция отображают список
`listening_links`, объединённый с прямыми ссылками каталога, без повторов площадки.
Для Zig нет специального исключения или вручную прописанного Spotify ID.

Источники работают независимо: Apple Search, Deezer Search, отношения релизов
MusicBrainz и автоматические ссылки публичной страницы album.link. Проверяются
название, полный состав исполнителей, для группы MusicBrainz — год; неоднозначные
совпадения пропускаются. Номера томов и названия специальных изданий сохраняются.
Все сетевые запросы ограничены, соблюдаются robots.txt и интервалы запросов.
Старый одноплатформенный кэш v3 заменён ключами v4. Прежние чаты и коллекция
получают новые ссылки при открытии карточки без изменения снимков рекомендаций.

Показываются прямые страницы альбомов на 14 поддерживаемых площадках; у YouTube
принимаются только автоматически сформированные альбомные плейлисты OLAK5uy.
Нет кнопок поиска, ссылок на отдельные треки и выдуманных адресов. В ответе API
сохраняется источник каждой найденной ссылки. Пользователь видит индикатор поиска
и отдельное сообщение при частичной недоступности источников.

Источник соответствий Zig: [издания MusicBrainz](https://musicbrainz.org/release-group/ae04379e-7502-4a9e-959c-45a8cffbed29),
[страница album.link](https://album.link/d/763788411).
[Найденная страница Spotify](https://open.spotify.com/album/6A2IQLnp76gVz8OJLWWVxF)
дополнительно проверена: это Zig исполнителя Poppy.

Обновлены все 45 ранее открытых релизов из действующего каталога, обнаруженные в
старом кэше: 36 ссылок превратились в 290; число релизов хотя бы с одной ссылкой
увеличилось с 36 до 40. Spotify появился у 25 релизов вместо нуля. Это ограниченная
проверка ранее открытых карточек, не полный обход 45 643 записей каталога.

Точные соответствия пока не найдены для Crime Waves, Niggas on the Moon,
Truly Yours, 2010 YOUTUBE CORE и Sniperlite. У части запросов MusicBrainz были
временные ошибки; успешные ссылки других источников сохранены, неполные результаты
обновляются при последующем открытии после истечения короткого кэша. Отсутствие
ссылки не доказывает отсутствие альбома на платформе. Наличие соответствия в
публичной базе не гарантирует воспроизведение в конкретной стране или подписке.
Ограничение MusicBrainz — максимум 300 изданий на группу, с явным статусом partial.

## Проверки и установка

- 838 Python-тестов прошли; 60 целевых тестов повторно прошли после финальных правок.
- 49 браузерных проверок прошли: все кнопки одновременно, объединение источников,
  загрузка, частичная ошибка, обновление страницы и отсутствие горизонтального
  переполнения на телефоне, а также прежние сценарии сайта.
- Восемь offline-сценариев release gate прошли.
- Сборка TypeScript/Vite и Ruff прошли.
- API с реальным каталогом и обновлённым кэшем возвращает 14 площадок Zig;
  анонимный доступ — 401, неизвестный релиз — 404.
- Сервер на 127.0.0.1:8000 перезапущен после резервного копирования. Новые контракт
  и frontend обслуживаются; контрольные суммы чатов, коллекции, оценок и настроек
  до/после перезапуска совпали.
- Платных вызовов модели не было; ключи сервисов для этого механизма не нужны.
