# RYM: проверенный исторический CSV с GitHub

Проверено 28 октября 2026 года. Применён ECC `search-first`: просмотр существующих
источников, затем проверка файлов и решение об использовании. GitHub CLI сообщил
о невалидном токене, поэтому использовались публичные GitHub API/raw URLs без
авторизации. Специализированного GitHub search MCP нет. Поиск пакетов не нужен
для загрузки уже опубликованного CSV; чужие программы не запускались.

## Как использовать

Использовать raw CSV: разделить жанры/дескрипторы по запятой и нормализовать
пробелы внутри каждого значения. Авторский `clean.R` удаляет пробелы и пытается
восстановить их по регистру; например, `male vocals` превращается в `malevocals`.
Очистка также подставляет январь/первое число для неполных дат. Эти преобразования
не нужны нашему импорту. Оба скрипта сохранены только для чтения.

Это отдельный исторический набор метаданных и общих оценок. `observed_at` должен
остаться `null`; дата скачивания и Git commit не делают рейтинг свежим. В строках
нет RYM release URL, RYM ID или MusicBrainz ID. Не создавать URL из названия,
не выполнять автоматическое каноническое объединение и не считать общие оценки
личными предпочтениями пользователя. Чарт популярных альбомов не закрывает
задачу поиска действительно малоизвестных релизов.

В просмотренном дереве репозитория нет LICENSE/COPYING; GitHub API вернул
`license: null`. Лицензия самого набора **не установлена**. Локальное исследование
публичного файла выполнено; право на перераспространение этим не подтверждается.
[Связанный Kaggle dataset](https://www.kaggle.com/datasets/tobennao/rym-top-5000)
найден, но доступный HTML не дал проверить отдельное заявление о лицензии.

| [wjkba/rym-charts](https://github.com/wjkba/rym-charts) | Приложение для пользовательских CSV; не источник полного каталога |

Итог решения `search-first`: использовать проверенный публичный снимок через
тонкий исторический импорт. Новый scraper или обход блокировок для получения
этих 5 000 строк не понадобился. Сам RYM в рамках этой задачи не запрашивался.
