# Реально полученные данные RYM и AOTY

2026-10-28 получены открыто опубликованные исторические выгрузки обоих сайтов через GitHub. Это реальные данные сторонних издателей, **не синтетические HTML fixtures**. Прямой сбор страниц RYM/AOTY по-прежнему не подтверждён.

| Источник | Получено и нормализовано | Файл |
|---|---|---|
| RYM | 5 000 строк, публикация в репозитории 2022 года | `data/community/rym-historical/releases.jsonl` |
| AOTY | 6 703 строки / 6 702 уникальных URL, файл опубликован 26.06.2024 | `data/community/aoty-historical/releases.jsonl` |
| Публичный AOTY API | Один настоящий ответ из кеша: OutKast — Aquemini; другие два пробных запроса дали 500 | `artifacts/source-research/tools/aoty-album-response.json` |

**11 703 — число строк двух исторических источников, не число уникальных альбомов.** Наборы пересекаются между собой. Один дубликат AOTY сохранён с предупреждением для проверки. Все строки прошли нормализацию, quarantine пуст; это проверка структуры, не независимое подтверждение каждой оценки.

## Откуда взяты файлы

RYM: [okanitobe/RateYourMusic](https://github.com/okanitobe/RateYourMusic/tree/7875b017e16de862d1971ebe1e83c8f1f16e1370), файл `Kaggle uploads/rym_raw1.csv`. Сохранены исходные пробелы внутри названий жанров/descriptors и неполные даты. Авторская версия clean не используется: она склеивает слова и дополняет отсутствующие месяц/день. Снимок содержит 627 строк с hip-hop/rap-метками и всех пяти любимых исполнителей. [Подробная проверка](rym-github-research.md).

AOTY: [rheera/album-of-the-year-analysis](https://github.com/rheera/album-of-the-year-analysis/tree/2801018ed93594efe29e35b6fff7661795517717), файл `albums_data_added_1955_2024.xlsx`. Извлечение выполнено собственным скриптом через ZIP/XML, без запуска кода автора или формул Excel. В исходнике 895 строк без даты релиза; год чарта не подставляется вместо неё. Все пять любимых исполнителей присутствуют. [Подробная проверка](aoty-github-research.md).

Публичный API: [edideaur/AOTY-api](https://github.com/edideaur/AOTY-api). Запрос `https://aoty.prigoana.com/album?slug=2915&minimal=true&cache=true` действительно вернул HTTP 200 и `X-Cache: HIT`. Устойчивость не подтверждена: два других пробных запроса дали HTTP 500. Возраст кеша неизвестен. [Запросы, ответы и исследование инструментов](music-source-tools.md).

## Что доступно для работы

Нормализованный JSONL содержит название, целую строку исполнителей, исходные жанры, descriptors RYM, год при наличии, общественный рейтинг с исходной шкалой и заявленное число оценок. У RYM нет URL/ID релиза в исходном CSV, поэтому они остаются `null`; локальный `row_id` обозначает строку снимка. У AOTY сохранён numeric ID и URL.

`observed_at=null`: точная дата измерения оценок неизвестна. Дата скачивания и Git-коммита сохранены в acquisition provenance, а дата нормализации — отдельно. У обоих источников показатели помечены как `publisher_reported_community_aggregate`, `count_semantics_verified=false`. В коде автора AOTY найдено извлечение числа без проверки слова ratings/reviews, поэтому смысл счётчика нельзя считать независимо установленным.

Эти файлы доступны для анализа и подключены к [первому единому каталогу](unified-catalog.md) `data/unified/community-v1/catalog.json`. Из 11 703 строк включены 11 550; 153 неоднозначные строки оставлены в `pending.jsonl` вне выдачи. Итог первого снимка — 9 903 релиза, 4 805 записи исполнителей/совместных credits, 408 жанровых узлов. Прежние 520 MusicBrainz ID и датированные наблюдения сохранены. С 2026-11-02 используется [расширенный снимок из 45 635 релизов](catalog-expansion-vibes.md); исходные файлы не переписаны.

Автоматические связи принимаются по консервативным правилам идентичности, а не только по похожему названию; правила и основания записаны в `matching.json`. Это проверяемые эвристические связи, не независимо подтверждённые MBID от RYM/AOTY. Жанры сопоставляются через версионируемую taxonomy; только основные сопоставленные метки задают eligibility, вторичные метки сохраняются отдельно. У 557 релизов основного жанра нет.

Исторические рейтинги хранятся в `historical_observations`, а не в датированных `observations`. Шкалы RYM 0–5 и AOTY 0–100 не усредняются, `observed_at` остаётся `null`, смысл счётчиков остаётся неподтверждённым. Эти значения не используются как свежий сигнал малоизвестности и не превращаются в личные лайки/дизлайки.

[Попарный eval](entity-matching-eval.md) содержит 50 реальных пар с предварительными агентскими метками и 6 отдельных синтетических ловушек. Первый результат: 27 совпадений из 30 положительных пар, 0 ложных объединений на 14 отрицательных и 0 неподтверждённых объединений на 6 спорных. Это не независимая человеческая разметка и не оценка общей точности каталога.

Оба снимка отобраны из популярных/высоко оценённых чартов. Они полезны для знакомства с жанрами и сигналами качества, но не дают репрезентативной выборки underground-релизов или доказательства текущей малоизвестности. Лицензия публикаций не указана; локальные копии не опубликованы нами, право дальнейшего распространения не установлено.

## Повторить нормализацию без сети

```bash
uv run python -m discovery.catalog.community \
  --source rym \
  --input artifacts/source-research/rym/rym_raw1.csv \
  --provenance artifacts/source-research/rym/provenance.json \
  --output-dir artifacts/community-replay/rym

uv run python -m discovery.catalog.community \
  --source aoty \
  --input artifacts/source-research/aoty/raw.jsonl \
  --provenance artifacts/source-research/aoty/manifest.json \
  --output-dir artifacts/community-replay/aoty
```

Выходные директории должны быть новыми. Импорт сверяет источник, fixture-статус и SHA-256 файла с acquisition manifest, отклоняет изменённый ввод и сохраняет неизвестные данные неизвестными. Повторно скачивать сайты для воспроизведения не требуется. Исходные файлы и скрипт извлечения AOTY находятся в `artifacts/source-research/`, нормализованные данные — в `data/community/`.
