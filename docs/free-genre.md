# Свободный жанр — 2026-11-04

В «Настройки подборки → Жанр поиска» первым пунктом доступен **«Все жанры»**.
После «Применить и подобрать» поиск работает по всему текущему каталогу.
Можно также написать «Все жанры», «Свободный жанр», «Без привязки к жанру»
или «Подбери из всех жанров»: чат предложит сменить фильтры с подтверждением.
Прежние чаты и их закреплённые жанры автоматически не меняются.

Режим сохраняется в диалоге и профиле после перезапуска. При переходе
в него через настройки снимаются прежние строгие поджанры; другие
пожелания и исключения сохраняются. При желании можно ограничить свободный
поиск несколькими направлениями через список строгих поджанров.
При переходе обратно к конкретному жанру интерфейс очищает зависимые
настройки, как и прежде, чтобы не оставлять несовместимые фильтры.

## Подбор

- Область `all` виртуальная: в саму таксономию и каталог она не записывается.
  Состав, хеш и версии снимка каталога сохраняются.
- Используются явные оценки, любимые исполнители и избегаемые жанры из всех
  разделов профиля. Они не копируются в настройки других разделов.
  Дополнительные предпочтения, заданные в разделе «Все жанры», учитываются
  и при последующем поиске в конкретном направлении.
- «Уже знаю», оценки прослушанного, исключения исполнителей, правило
  «только по прямому запросу» и личный лимит популярных остаются действующими.
- При сравнимой релевантности подборщик предпочитает разнообразие крупных
  направлений, а не только разных узких тегов одного жанра. Это мягкий штраф
  повторяемости, не обязательная квота жанров и не обещание пяти разных стилей.
- Релизы без определённого жанра доступны в свободном поиске; карточка честно
  сообщает об отсутствии жанра. При остальных равных их скор ниже на 0.05,
  чтобы нехватка данных не выглядела доказательством разнообразия.
- Редкость по счётчикам оценивается только внутри подтверждённых жанровых
  групп. Общая выборка `all` не становится общей шкалой популярности джаза,
  рэпа, поп-музыки и других направлений. Неизвестность остаётся неизвестностью.
- Звуковые пожелания используют прежние Vibe/Descriptors с порядковыми весами.
  Свободный текст не превращается в неявный лайк или обучающую метку.

ИИ получает `all` в словаре допустимых областей и инструкции рекомендовать
без требования выбрать жанр/исполнителя. При свободном поиске в ограниченный
контекст сначала попадают упомянутые жанры, ориентиры и крупные направления.
Остальные ограничения контекста, бюджета, повторных сообщений и подтверждения
фильтров прежние. Бесплатная кнопка подбора также поддерживает `all`.

## Совместимость и проверки

Ранжировщик — `baseline-v5-free-genre` (с 2026-11-08 текущая версия
`baseline-v6-model-correction`: модель стала поправкой к baseline, релизы без
специфичных жанровых тегов не считаются «далёкими»). Признаки остаются
`genre-tags-v2-artist-frequency`; таксономия не меняется.
Модели без отдельной валидации области `all` используют обычный fallback.
API по-прежнему принимает строку `genre_scope_id`; значение `all` и его
семантика описаны в OpenAPI. Общий поиск жанров возвращает виртуальный пункт,
а запрос поджанров для `all` — только реальные узлы каталога.

Проверки включают многожанровую выдачу, сохранение вкуса и исключений,
строгие поджанры, Vibe, неизвестный жанр, отсутствие общей шкалы редкости,
предложения ИИ с подтверждением, идемпотентность и сохранение после открытия
базы заново. Браузер: свободная подборка → уточнение ИИ → перезагрузка →
переход к джазу. Провайдер в браузере и диалоговых тестах замокан.

Отчёты: `artifacts/evals/free-genre-20261104/`. Полный реальный каталог
проверяется на одноразовой резервной копии аккаунта; личная история не
изменяется. Платных вызовов в задаче не выполняется. Тесты проверяют механику,
а не гарантируют субъективное музыкальное попадание.

Итог: **773 Python-теста, 8/8 офлайн-сценариев и 30/30 браузерных
проверок прошли**. TypeScript/Vite и Ruff пройдены. На копии реального
аккаунта полный каталог дал пять карточек без прослушанных и запрещённых
исполнителей; повтор сообщения вернул сохранённый результат. Хеш каталога
не изменился. Запрос с записью снимка занял около 32 секунд; это проверка
функциональности, не обещание такой же задержки на каждом компьютере.
