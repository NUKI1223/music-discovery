# Доступ HTML-парсеров RYM/AOTY

Проверка: **2026-10-28, около 12:43 UTC**. Парсинг сохранённого HTML и загрузка страницы — отдельные операции. Рабочие тесты парсера не доказывают доступность live-сайта или право распространять его данные.

## Реально выполненные probes

Выполнено по одному обычному HTTPS GET официального robots.txt через curl. Использован честный User-Agent `MusicDiscovery/0.1 (explicit single-page research fetch; robots compliance)`, без браузерной маскировки, повторов, перенаправлений, прокси обхода, авторизации или решения challenge. Ограничения команды: 20 секунд и 262144 байта.

| Адрес | Реальный результат | Следующее действие |
|---|---|---|
| [RYM robots.txt](https://rateyourmusic.com/robots.txt) | HTTP 200, `text/plain`; группа `User-agent: *` содержит `Disallow: /`. В комментарии владелец также указывает ограничение автоматизированного доступа без express permission | `ROBOTS_DENIED`: release-страницы не запрашивались |
| [AOTY robots.txt](https://www.albumoftheyear.org/robots.txt) | HTTP 403; заголовок `cf-mitigated: challenge` | `ROBOTS_UNAVAILABLE`: album-страницы не запрашивались |

Исключения в robots для других конкретных клиентов не используются: загрузчик не выдаёт себя за Googlebot, браузер, поисковый агент или иной разрешённый клиент. Заголовки cookies и технические идентификаторы ответов в документацию и provenance не копируются.

**Подтверждённых успешных live-capture страниц релизов нет.** Проверка сохранённого HTML выполняется отдельно на явно маркированных тестовых данных. Положительные unit tests не меняют результаты probes.

## Ограничения загрузчика

API: `discovery.catalog.web.fetch.fetch_html(url, outputdir, *, client=None)`. Возвращает `FetchResult` с полями `html_path`, `provenance_path`, `url`, `captured_at`, `sha256`, `source`. `FetchBlocked` содержит безопасный текст, машинный `code` и необязательный `status_code`; тело ответа, команды и credentials в ошибку не включаются.

- Один явный вызов = свежая проверка robots.txt и максимум одна указанная пользователем страница. Ссылки со страницы не обходятся; автозапуска, очереди и расписания нет.
- Разрешены только HTTPS, точные hosts `rateyourmusic.com` и `www.albumoftheyear.org`, пути RYM `/release/album|ep|mixtape/<artist>/<release>/` и AOTY `/album/<id>-<slug>.php`. Username/password, порты, query string, fragment, encoded traversal, charts/search/account и посторонние hosts отклоняются до HTTP.
- Стандартный `urllib.robotparser` проверяет разрешение для `MusicDiscovery`, но не реализует всю современную семантику robots. Поэтому перед ним выполняется консервативная проверка: wildcard `*` и конечный `$` в путях, несколько подходящих групп (включая повторные `User-agent: *`), а также сочетание разрешающих и запрещающих правил в подходящей группе дают `ROBOTS_UNSUPPORTED`. Загрузчик не пытается самостоятельно вычислить приоритет самого специфичного правила. Это может остановить страницу, которую полноценный RFC-парсер разрешил бы, но исключает молчаливое игнорирование более строгого запрета. Некорректный `Request-rate`, включая `0/10` и `1/0`, даёт `ROBOTS_INVALID`; неверный `Crawl-delay` также останавливает загрузку. Недоступный, нераспознаваемый, неверно кодированный или запрещающий robots останавливает загрузку. HTTP 404 для robots здесь также означает остановку. Разрешение из старого кеша не подставляется.
- Все HTTP-перенаправления отклоняются, включая переход на другой разрешённый host. HTTP 403/429 и остальные не-200 не повторяются. Challenge в заголовках или HTML останавливает обработку. Не выполняются JavaScript, CAPTCHA, вход, browser automation или смена IP.
- Между запросами минимум 3 секунды; более строгие robots `Crawl-delay`/`Request-rate` учитываются. Общий для процессов данного OS-пользователя файл `~/.cache/music-discovery/web-fetch-rate.json` защищён файловой блокировкой. Если limiter недоступен или повреждён, запрос запрещается. Нельзя считать этот механизм глобальной квотой между разными компьютерами/OS-пользователями.
- Robots ограничен 262144 байтами, HTML — 2000000 байтами. Проверяется Content-Length и фактически полученный размер. Запрашивается `Accept-Encoding: identity`; неожиданное сжатие отклоняется. Операции I/O ограничены 10 секундами; общий streaming deadline — 45 секунд с проверкой после каждого чтения. Из-за синхронного блокирующего I/O wall time может превысить deadline на один I/O timeout. Произвольный пользовательский transport должен сам соблюдать HTTPX timeout; тестовый `client` не превращает некооперативный transport в принудительно прерываемый поток.
- Сохраняется только HTTP 200 с HTML MIME, распознаваемой структурой страницы альбома и без известных признаков challenge. Загрузчик и локальные парсеры используют общий `page_is_blocked`: отдельный заголовок ошибки и структурные challenge-маркеры блокируются, но название настоящего альбома вроде «Access Denied» само по себе не считается отказом сервера, если оно подтверждено структурой релиза и присутствует в заголовке страницы. Это консервативная техническая проверка, не доказательство истинности всех полей: дальнейший парсер проверяет содержимое. Изменение вёрстки может дать `NOT_RELEASE_PAGE`.
- Каждый успешный capture получает отдельную директорию с исходным `page.html` и `provenance.json`: URL, UTC-время, SHA-256, размер, HTTP-статус, MIME, User-Agent, URL/время/hash robots и способ получения. Предыдущий snapshot не перезаписывается. При блокировке HTML snapshot не создаётся.
- Fresh HTTPX Request не наследует cookies, Authorization, auth или default headers переданного client. Собственный клиент не использует proxy-переменные окружения. Cookie-заголовки ответов не попадают в provenance. Собранный HTML остаётся недоверенным вводом; загрузчик его не исполняет.

## Условия использования и границы результата

Robots-разрешение и HTTP 200 **не являются лицензией**. В provenance явно записывается `rights_status=not_established_by_technical_access`. Текущие [AOTY Terms of Use](https://www.albumoftheyear.org/terms-of-use/) ограничивают автоматизированный доступ и систематическую сборку базы; доступ к API/data partnership описывается отдельно. RYM robots ссылается на [RYM ToS](https://rateyourmusic.com/tos); актуальный полный текст ToS в исследовании не был доступен. Подробности, личные экспорты и ограничения сторонних наборов — в [rym-aoty-access.md](rym-aoty-access.md).

Это предупреждение о свойствах источников, а не выдуманный дополнительный диалог согласия с пользователем. Код действует по фактическим сетевым и robots-ограничениям; он не содержит переключателя их обхода. Наличие локального HTML не устанавливает автоматически право на распространение извлечённой базы.

## Offline-проверка

```bash
.venv/bin/pytest -q tests/catalog/web/test_fetch.py
```

Тесты используют HTTPX MockTransport, локальный временный rate-state и управляемые часы. Они проверяют allowlist/SSRF-границы, запрет перенаправлений, отсутствие page-запроса при запрещённом/недоступном/неподдерживаемом robots, wildcard и конфликтующие группы/правила, `Request-rate: 0/10`, отказ на challenge/403/429, названия альбомов с потенциально неоднозначными словами, размер streaming-ответа, deadline, отсутствие повторов, интервалы между вызовами, сохранение raw bytes/hash и отсутствие credentials из client в запросах/provenance. Автоматических live-запросов в тестах нет.
