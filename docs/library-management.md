# Диалоги и коллекция

Изменение 2026-11-06.

## Пользовательский сценарий

- Обновление страницы сохраняет открытый раздел (чат, коллекция, профиль)
  и выбранный диалог. Состояние хранится в браузере отдельно для аккаунта
  и вкладки; при загрузке данные снова читаются с сервера. Удалённый чат
  заменяется пустым экраном диалога с пояснением. Незавершённые запросы
  автоматически не отправляются повторно.
- Корзина появляется поверх правого края названия диалога при наведении
  или фокусе клавиатуры, не сжимая строку; на сенсорном экране видна постоянно.
  Нажатие открывает подтверждение. Удаляются
  переписка, заметки, краткая память и индекс карточек этого чата.
  Альбомы в коллекции и оценки остаются; источник обозначается «Удалённый чат».
  Выполняющийся запрос сначала должен завершиться.
- В коллекции есть поиск по названию и исполнителю, отбор по личной отметке,
  чату, жанру и минимальной исторической оценке AOTY/RYM. Условия совмещаются.
- Сортировка: недавно отмеченные, название, исполнитель, год, оценка AOTY
  либо RYM. Шкалы источников не смешиваются; неизвестные оценки идут в конце
  и не проходят фильтр минимальной оценки, даже если порог равен нулю.
- Группировка: единый список, по чатам либо по жанрам. Релиз может быть
  показан в нескольких группах: учитываются все диалоги, где он встречался,
  и все жанры релиза. Общий счётчик считает уникальные альбомы.
- По умолчанию и после сброса фильтров включена группировка по чатам.
  Название чата показано один раз над всей сеткой альбомов, переносится
  при нехватке места и открывает действующий чат по нажатию. Подписи над
  отдельными карточками в этом режиме убраны. В едином списке и группировке
  по жанрам источники остаются у карточек, чтобы сохранить связь с чатами.
- Ссылки на действующие чаты открывают переписку. Импортированные альбомы
  без переписки относятся к «Без чата».
- Карточки загружаются в отображение порциями по 24 уникальных альбома,
  поиск и сортировка работают по всей коллекции.
- «Убрать из коллекции» для альбома и «Очистить коллекцию» для всего списка
  требуют подтверждения. Очистка охватывает и скрытые текущими фильтрами
  элементы; количество явно указано в диалоге.
- Галочка **«Удалить из памяти»** по умолчанию выключена. Без неё альбомы
  скрываются из коллекции, оценки остаются, а дальнейшие рекомендации
  исключают эти альбомы, включая лишь отложенные на потом.
- С галочкой сбрасываются все оценки и отметки выбранных альбомов во всех
  жанровых областях. Они снова могут попасть в новые диалоги. Старый чат
  по-прежнему не повторяет уже показанные в нём релизы. Переписка, настройки
  исполнителей, ограничения популярности и выбранные жанры сохраняются.
- Новая явная отметка в прежнем чате возвращает скрытый альбом в коллекцию.
  Повтор доставки старой отметки этого не делает. Очистка списка не меняет
  альбомы, которые уже были убраны из коллекции раньше.

## Хранение и API

- Все действия работают только с SQLite текущего аккаунта, выбранной сервером.
- `DELETE /api/chats/{chat_id}`: атомарное удаление чата с проверкой pending.
  Для коллекции сохраняются только ID чата и ID релизов без текста и названия
  диалога. Сохраняются использованные ключи запросов: перенос старого
  `message_id` в новый чат не создаёт повторный платный вызов.
- `DELETE /api/collection` и `DELETE /api/collection/{release_id}`:
  `forget=false` скрывает и исключает; `forget=true` дополнительно отзывает
  отметки. Query-параметр включён в OpenAPI и клиентские типы.
- `hidden_collection` хранит границу последовательности отметок и исключение
  из рекомендаций. Новая явная отметка после границы может вернуть карточку.
- `revoked_feedback` отзывает события без освобождения ключей идемпотентности.
  `Store.feedback()` выдаёт только действующие события: профиль, экспорт и
  последующее обучение не используют отозванные оценки. Сбрасываются также
  соответствующие оценки альбомов в импортированном базовом профиле.
- Исходные записи журнала и снимки решений сохраняются для целостности и
  воспроизводимости; «Удалить из памяти» означает отзыв предпочтений, а не
  физическое стирание журнала, резервных копий или переобучение ранее
  экспортированных моделей. Журнал не передаётся frontend.
- CLI-импорт переносит границы скрытия и отозванные события, сохраняя их seq;
  импорт не должен воскрешать удалённые из коллекции записи.
- GET коллекции дополняет карточку `chats` и `saved_at`. Связи старых альбомов
  извлекаются из сохранённых сообщений, без ручной миграции каталога.
- DELETE защищены существующими Origin/CSRF-проверками и серверной сессией.
  Управление библиотекой не вызывает OpenRouter.
