# Golden-набор и цикл обучения

Система рассчитана на любые музыкальные жанры. Три сценария из Word и четыре
описания rage-релизов — первый golden-набор, не граница возможностей системы.
Качество на нём не переносится автоматически на джаз, электронику или другие
жанры. Эталоны уже обсуждались при разработке: это регрессионная проверка,
не независимый слепой тест.

## Что входит

- `data/evals/user-recommendation-cases-v1.json`: три сценария из
  `testsoptions.docx`, исходные формулировки и уточнения пользователя.
- `data/evals/rage-sound-annotations-v1.json`: четыре описанных релиза;
  один непрослушанный и семь ожидающих ответа оставлены без звуковых меток.
- `data/evals/user-confirmed-inputs-v1.json`: только фильтры, подтверждённые
  в предыдущем диагностическом прогоне, плюс дата оценки. Эталонных ответов
  в этом файле нет. Запросы и контексты слушателя берутся из сценариев.

`build_gold_manifest` вычисляет хеши и защищённые IDs. Из обучения исключаются
релизы эталонных артистов, включая другие альбомы и коллаборации. Проверка
применяется к текущему и историческим каталогам. Совпадения имён используются
консервативно для исключения, не как доказательство идентичности. Неподтверждённый
Slug не возвращается в учитываемые положительные примеры.

Word содержит соответствие артистов запросу, а описания альбомов — звучание.
Ни то, ни другое не является явным лайком/дизлайком конкретного прослушанного
релиза, который можно подать в текущую модель вкуса. Самообучение на собственных
предсказаниях вместо пользовательских оценок не выполняется.

## Запуск без OpenRouter

```bash
.venv/bin/python -m discovery.evals.gold_run \
  --output artifacts/evals/gold-new-run.json
```

При наличии оригинала Word можно добавить
`--source-docx /home/vladk/Downloads/testsoptions.docx`: несовпадение SHA-256
отклоняет запуск и требует пересмотра переноса примеров. Для кандидата добавьте
`--model /absolute/path/experimental-artifact.json`.

Новый отчёт не перезаписывает старый. Код завершения 1 — провал структурных
проверок; 2 — ещё нужна оценка человека. Отсутствие данных не является успехом.
Кандидат действительно проходит через свою функцию вероятности и тот же
отбор карточек в изолированном режиме; неподтверждённый артефакт не включается
в сайт. В отчёте явно указано, применён ли кандидат или произошёл fallback.
Пересечение его training_release_ids с gold помечается contaminated, отсутствие
происхождения — unknown_training_provenance. Историческая защита дополнительно
фиксируется в отчётах автоматического обучения.

Проверяется подбор по фиксированным фильтрам, не понимание нового текста
моделью чата. Для проверки языка остаётся отдельный `discovery.evals.user_run
--live` с ограниченным бюджетом; в данном шаге он не вызывался.

## Текущий результат

Первый offline-прогон `artifacts/evals/gold-learning-baseline-20261101.json`
подтвердил хеш Word. Для Kendrick-сценария структурные проверки пройдены,
но музыкальное соответствие и известность ещё не подтверждены. В двух rage-
сценариях получены три карточки вместо пяти. Это провал полноты, а не успех.
Звуковой набор: `needs_audio_and_independent_predictions`. Пользователь сообщил,
что записей нет; словесные описания не заменены выдуманными аудиопризнаками.

Обучение на независимых оценках запускается [отдельным циклом](../autotraining.md).
Для будущих звуковых признаков есть [локальный анализатор](../audio-local.md).
Проверка аудиопайплайна на синтетике подтверждает вычисления и контракты;
она не подтверждает музыкальное качество или перенос между жанрами.

## Проверка реализации

Полный Python-прогон: 576 passed. После последних изменений отдельно прошли
83 проверки GOLD, автоматического обучения, аудио, ранжирования и serving,
в том числе новый случай обучения на джазе и метале. Ruff: без ошибок.
CLI аудио реально запущен на синтетическом WAV с изменением частоты; нейросети
allin1/Demucs не запускались. Повтор CLI обучения на отдельной пустой истории
вернул insufficient_data, затем skipped=true с тем же run_id, без создания
артефакта модели. Это проверка механизма, не обучение на данных аккаунта.

Финальные отчёты:
`artifacts/evals/gold-learning-verified-20261101.json` и
`artifacts/training/automation-smoke-20261101.json`. Все вызовы бесплатные,
OpenRouter не использовался. Постоянный процесс watch не запускался.
