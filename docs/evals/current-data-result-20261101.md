# Результат улучшения на текущих данных — 1 ноября 2026

Каталог не изменён: SHA-256 совпадает с исходным прогоном от 31 октября.
Модель осталась `openai/gpt-5.6-luna`. Работа остановлена на ограничениях данных,
по указанию пользователя. Музыкальное качество не объявлено доказанным.

## Что изменилось

- У запроса появились собственные исполнители-ориентиры. Они влияют на выбор
  вместо того, чтобы теряться среди общих предпочтений профиля.
- Можно явно исключить артиста-ориентира и других названных исполнителей.
  Пожелания показываются до подтверждения и сохраняются для следующих подборок.
- Используются имеющиеся описания источников: например, rhythmic, melodic,
  aggressive. Совпадение предпочтительного признака повышает оценку, нежелательного
  — снижает. Отсутствие описания остаётся неизвестностью, не доказательством.
- Surprise сильнее учитывает расстояние по жанровым меткам. Если мягкие квоты
  новизны не заполняются, подбор использует остальные допустимые варианты и
  предупреждает об этом, сохраняя строгие ограничения.
- Знакомые по профилю/прослушиваниям артисты получают меньший приоритет в explore
  и surprise. Это мягкое предпочтение, а не запрет и не измерение публичной известности.
- В настройках можно просмотреть и сбросить ориентиры и звуковые пожелания.
  Пожелания не превращаются в лайки и не меняют постоянный профиль автоматически.

## Почему работа остановлена

В каталоге **только три** релиза с основным жанром rage: Whole Lotta Red,
Skeletrix Language и 2093. Описания звучания есть только у Whole Lotta Red.
У остальных двух остаются жанры и исторические оценки. Из этих данных нельзя
надёжно вывести степень шума, агрессии или место на границе жанра. Перестановка
трёх карточек не создаёт пять разных рекомендаций и не доказывает понимание rage.

Во всём хип-хоп-разделе описания имеются у **531 из 1311 релизов**. Метка melodic
не измеряет долю пения/читки. Проверенной разметки публичной известности нет,
поэтому лимит «не более двух широко известных из пяти» не подтверждён.
Исторические счётчики AOTY/RYM и личная знакомость не подменяют эту разметку.

Для следующего существенного улучшения нужны дополнительные подтверждённые
релизы и сопоставимые описания: вокальная подача, мелодичность, плотность/шумность
и жёсткость звучания, границы жанра, отдельная известность исполнителя. Нужна
проверка на конкретных альбомах, а не перенос свойств артиста на всю дискографию.
Примеры пользователя сохраняются критериями оценки, не скрытым списком ответов.

## Проверка реализации

514 Python-тестов пройдены, включая прежние восемь синтетических сценариев.
13 браузерных сценариев пройдены, включая подтверждение ориентиров, исключение,
сохранение после перезагрузки и сброс. Сборка TypeScript/Vite и lint пройдены.
Это свидетельство работоспособности изменений; один live-прогон не является
статистической оценкой устойчивости или музыкальной полезности.

Повтор подтверждённых фильтров, без обращения к модели:

```bash
uv run python scripts/replay_user_filters.py \
  artifacts/evals/user-cases-current-data-20261101.json \
  --output artifacts/evals/another-offline-replay.json
```

Скрипт требует неизменные каталог, набор примеров и артефакт персональной модели;
новый путь результата обязателен. Все профили и истории тестовые и временные.
