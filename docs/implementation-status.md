## Исправления взаимного ревью

Исправлены смешивание demo/real истории, поддельные показанные решения, конкурентные дубликаты feedback, повторное использование изменённого каталога с тем же ID, неверное сочетание known/unknown, потеря familiarity в событиях иных типов, неограниченное ожидание agent callbacks, молчаливое снятие текстом жёстких фильтров, остановка baseline при повреждённом optional model, historical export corrections после cutoff и смешивание версий taxonomy/features в обучении.

Callbacks агента доверенные и только для чтения замороженных данных. Deadline ограничивает ожидание, но не убивает Python thread или уже ушедший provider request; поздний результат не сохраняется. Live `as_of` относится к свежести наблюдений каталога и не является историческим replay feedback.

Единый каталог использует `community-taxonomy-v1+6e4b3bae01a2`; для обучения предназначен `configs/supervised-unified.json`. Старый `configs/supervised.json` с `mb-tags-v2` сохранён. История решений не переписывается, разные taxonomy/features в один training run не смешиваются. Рейтинги сообществ не создают личных labels.

## Что остаётся для полезного музыкального продукта

Проверить спорные связи и жанры, расширить покрытие малоизвестных релизов и получить достаточные сопоставимые показатели известности. Затем накопить настоящие оценки, сравнить модель с baseline на отложенных данных и отдельно проверить discovery rate на прослушиваниях. До этого тесты подтверждают механику, но не обещание «действительно интересные малоизвестные варианты».

Запуск и команды: [README](../README.md). Методика: [learning pipeline](learning-pipeline.md). Источники и условия: [sources](sources.md). Журналы агентов: [agents](agents.md).

Терминальная панель `scripts/watch_agents.py` показывает реальные события сабагентов и прогресс сборщика; описания текущих задач находятся в `docs/agent-tasks.json`.

Реализованы [парсеры HTML RYM/AOTY](web-parsers.md) с раздельными пользовательскими и критическими оценками, исходными шкалами и provenance; отдельный загрузчик соблюдает robots и останавливается на блокировках. Код проверяется на синтетических страницах. Совместимость с живым HTML не подтверждена.

Другим путём получены [реальные исторические RYM/AOTY данные](community-data.md): 5 000 + 6 703 строки из публичных GitHub-выгрузок; нормализованы в `data/community/`, источник/fixture/hash проверяются перед импортом. Они подключены через документированные правила matching и taxonomy. Время измерения остаётся неизвестным, личных меток нет, показатели не становятся свежими наблюдениями. Публичный AOTY API дал один cached ответ и два HTTP 500; устойчивость и свежесть не подтверждены.
