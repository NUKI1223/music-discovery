# Music Discovery — личная музыкальная библиотека

Направление: спокойная домашняя библиотека, собранная вокруг альбомов, истории прослушивания и диалога. Жанр не задаёт оформление: продукт рассчитан на любую музыку. Цвет остаётся в подтверждённых обложках; без них используется честная нейтральная заглушка.

Исходный интерфейс проверен в браузере на временном учебном аккаунте: `artifacts/ui-redesign/before/`. Зелёный фон объединял почти все поверхности, мелкие подписи и повторяющиеся предупреждения скрывали основные действия. Настройки были слабо заметны, а подтверждение предложения только сохраняло фильтры.

## Решения

- Графитовые нейтральные поверхности, тёплый приглушённый акцент для выбранного состояния и основных действий. Без градиентов, свечения и декоративных эмодзи.
- Настройки подборки всегда доступны в шапке. На телефоне открываются нижней модальной панелью, на широком экране — отдельным диалогом. Нативный dialog удерживает фокус, Escape закрывает панель, отмена не записывает черновик.
- «Применить и подобрать» сохраняет подтверждённые фильтры, затем запускает бесплатную подборку. Синхронная блокировка предотвращает двойной клик; повтор после потери ответа использует тот же message_id. Для предложения идентификатор детерминирован из ID чата и сообщения. Применённое состояние сохраняется в sessionStorage аккаунта; сервер дополнительно обеспечивает идемпотентность.
- Карточка: обложка, название и исполнитель; причина рекомендации; существенная оговорка; источники и прослушивание; четыре явных действия обратной связи. Остальные оговорки свёрнуты. Исторические оценки округляются только для отображения, исходные шкалы сохраняются.
- Нормальный регистр текста, подписи от 12 px, основной текст 14–16 px, мобильные основные цели от 44 px. Контрастный фокус и reduced-motion. Значения основных фильтров переведены на русский; собственные имена и неизвестные каталожные жанры сохраняются.
- Два разных выбора исполнителей: постоянное «Только по прямому запросу» в профиле и явное «Только эти исполнители» для текущей подборки. Это не ось «мягкое/жёсткое»: описание звучания задаёт пользователь в конкретном запросе.

Дополнительно: профиль содержит включаемую общую политику известных исполнителей с явным максимумом 0, 1 или 2 исполнителя и строгим ограничением меньше половины подборки. Ноль означает только по прямому запросу; актуальный выбор пользователя — один. Интерфейс показывает покрытие явными пользовательскими метками; неизвестная популярность не объявляется малоизвестностью. Флаг, выбранный максимум и исходные свидетельства сохраняются при смене жанра и стартового вкуса. Явный запрос исполнителя — отдельное исключение для текущего подбора.

## Применённые инструкции и авторство

Использованы локальные навыки [UI UX Pro Max](/home/vladk/.codex/skills/ui-ux-pro-max/SKILL.md) и [Unslop](/home/vladk/.codex/skills/unslop/SKILL.md). Повторный поиск Pro Max `music library desktop app` в product вернул музыкальное обучение и редактор видео — подходящего продуктового соответствия не найдено. Эти шаблоны не переносились. Использованы относящиеся к задаче правила видимого фокуса, понятных состояний, контраста, сенсорных целей и читаемой типографики; визуальное направление выбрано по существующему продукту.

Методология Unslop — **Damir Sokolovsky**, [проект](https://heydamir.design/unslop), [автор](https://x.com/heydamir), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Адаптированы рекомендации по нейтральной тёмной палитре, плотности, типографике и последовательной визуальной проверке. CSS и компоненты написаны для этого приложения; внешний UI-kit, шрифты и иконки не загружаются.

Проверка визуального результата и браузерные артефакты: `artifacts/ui-redesign/after/` и Playwright `test-results/`. Скриншоты используют учебный каталог: названия DEMO и предупреждения о вымышленных данных оставлены намеренно.
