## Unslop: направление и визуальная проверка

1. **Продукт:** личная библиотека музыкальных открытий с помощником.
2. **Характер:** спокойный, собранный, немного тёплый.
3. **Среда:** полка альбомов и заметки о прослушивании, графитовые панели.
4. **Акценты:** настоящие обложки, названия и артисты; без выдуманных изображений.
5. **Отличительный элемент:** понятная отметка прослушивания рядом с релизом.

Обнаруженное до изменений: панель коллекции сдвигала первый альбом на мобильном
экране до ~720 px; заголовок входа был общим приветствием; выбор настроек чата
отображался и на страницах коллекции/профиля; отсутствовали необходимые
семантические заголовки и основной landmark onboarding.

Проходы:

| Проход | Изменения |
| --- | --- |
| Отступы | Уплотнена шапка коллекции, оставлен постоянный поиск; дополнительные фильтры сворачиваются |
| Цвет | Сохранены графитовые поверхности и существующий тёплый акцент; новых декоративных цветов нет |
| Иконки | Сохранён единый SVG-набор; дополнительные декоративные значки не добавлялись |
| Текст | «Вход в библиотеку», пояснение черновика стартового вкуса, корректная ошибка параметров вместо сообщения о пароле |
| Типографика | Семантический заголовок чата и подзаголовки списков без увеличения панели чата |
| Компоновка | Настройки подборки показываются только в чате; фильтры коллекции не занимают весь первый экран |
| Детали | Карточки с радиусом 12 px, видимое состояние загрузки навигации, сохранение существующих focus-стилей |
| Изображения | Существующие подтверждённые обложки и честные заглушки; изображения не генерировались |
| Движение | Сохранены короткие переходы и индикатор выполняющегося запроса; новых эффектов нет |

На одном и том же тестовом экране шириной 375 px первая карточка коллекции
поднялась с **719,9 до 448,4 px**, примерно на 271 px. Проверены 375, 768,
1440 px; прежние сценарии также проверяют 320 px. Горизонтального переполнения
не обнаружено. Автоматического сравнения с утверждённым пиксельным эталоном нет:
статус этой отдельной проверки **INCONCLUSIVE**. Скриншоты до/после сохранены
и осмотрены; ожидаемые изменения радиуса и текста внесены в браузерные проверки.

## Исправленные дефекты

| Проблема | Исправление и доказательство |
| --- | --- |
| HTML pattern логина некорректен в современном Chromium (`v` flag), браузер игнорирует проверку символов | Экранирован дефис; проверены запрещённые и допустимые логины, ошибок regex нет |
| Стартовый вкус сохранялся на сервере до нажатия «Сохранить» | `POST /profile/starter?preview=true` возвращает черновик; отмена не меняет аккаунт; прежний API без preview совместим |
| Несохранённый выбор исполнителей пропадал после переключения жанра и обратно | Раздельные черновики по жанрам, защита от устаревших ответов, блокировка формы во время сохранения/загрузки |
| Загрузки чата и коллекции могли пересекаться с отправкой сообщения и менять экран поздним ответом | Общая блокировка навигации на время запроса и видимый статус загрузки; сценарий с задержанным ответом |
| Настройки подборки на странице коллекции могли отправить подбор в фоновый чат | Кнопка доступна только в контексте чата |
| Множество медленных поисков обложек занимали общие API-потоки | Асинхронная постановка задач, отдельный лимит двух потоков; проверено, что история доступна во время поиска |
| Даже готовая обложка ожидала общей блокировки поискового кеша | Проверка сохранённого результата до блокировки; тест с намеренно занятой блокировкой |
| Любая ошибка параметров API сообщала о требованиях к логину/паролю | Раздельные сообщения для auth и остальных API, без отражения входных данных |
| Onboarding без `main`, чат без h1, коллекция перескакивала с h1 на h3 | Исправлены landmarks и иерархия заголовков; axe на основных экранах не находит нарушений |
| README описывал старый каталог и старое покрытие Vibe | Синхронизированы путь каталога, количество записей, свободный жанр и поведение стартового вкуса |

```bash
uv run ruff check .
uv run python -m discovery.evals.run --suite release --offline \
  --output artifacts/evals/ecc-unslop-20261106/release.json
npm --prefix frontend run build
cd frontend
npm run test:e2e
```

Для отдельного визуального отчёта запустить демо-сервер в одном терминале:

```bash
DISCOVERY_DOTENV=0 uv run python scripts/web_test_server.py \
  --data-dir /tmp/discovery-ecc-visual --port 8767
```

В другом терминале из корня проекта:

```bash
node scripts/audit-web-ui.mjs after
```

Скрипт работает только с локальным портом **8767** и создаёт тестовый аккаунт.
Не запускать на этом порту сервер с личными данными вместо демо-сервера.

Отчёты: `artifacts/evals/ecc-unslop-20261106/`.

- Python: **792 теста**, offline-сценарии: **8**, все прошли.
- Playwright: **43 теста**, все прошли; итоговый код завершения процесса **0**.
- `ruff`, TypeScript, сборка Vite: прошли.
- axe: **0 нарушений** в повторном аудите; проверка включает WCAG 2/2.1/2.2 AA
  и best-practice. Это не сертификат полной доступности: экранный читатель
  вручную не использовался, хотя клавиатурные сценарии проверены.

Внешние API живьём не проверялись. Их доступность, региональное наличие альбома,
субъективное качество ответа выбранной модели и реальная аудиоаналитика остаются
отдельными проверками. Для локального использования пройденные сценарии готовы;
публичное размещение не являлось предметом этой работы.

## Применение на локальном сайте

Сервер `127.0.0.1:8000` перезапущен с исправлениями. Перед перезапуском
проверено отсутствие выполняющихся сообщений и сделаны SQLite-копии аккаунтов
и пользовательских баз в `runtime/backups/ecc-unslop-20261106T102454Z/`.
После запуска совпали контрольные суммы таблиц истории, оценок, настроек,
памяти чатов, скрытой коллекции и записей об удалении. Пользовательские данные
сохранены. Главная страница отвечает 200, коллекция без входа — 401; проверены
новый API черновика вкуса и точное совпадение отдаваемого JavaScript со сборкой.
Подробности проверки: `artifacts/evals/ecc-unslop-20261106/restart.json`.
