# Работа с Claude Code в этом проекте

Claude Code уже установлен в пользовательской среде. Открой терминал в корне репозитория и запусти:

```bash
cd ~/Projects/hiphop-discovery
claude
```

При первом запуске Claude Code может попросить войти в аккаунт Anthropic или подтвердить способ оплаты. Это авторизация самого Claude Code; ключ OpenRouter из `.env` для этого не подходит и Claude его читать не должен.

В корне проекта есть `CLAUDE.md`: Claude Code автоматически загружает его как проектные инструкции. Там описаны архитектура сайта, продуктовые правила, безопасная работа с личными данными и команды проекта. Для разбора последнего диалога с музыкальным ботом используй `/recap` или напиши «Рекап».

Пример запроса:

> Разберись, почему фильтр малоизвестности не сработал в последнем чате. Сначала воспроизведи проблему на тестовых данных, затем исправь.

Или:

> Рекап моего последнего диалога с ботом. Скажи, где он неверно понял запрос. Код пока не меняй.

Claude работает с теми же файлами, что и остальные инструменты в этой папке. Не запускай параллельно второго помощника, который правит те же файлы. Проект под Git с 2026-11-08 (коммит `442e8c2`), правки видны в `git diff`. Пользовательские базы `runtime/`, `artifacts/`, `.env` и распакованные каталоги в Git не входят, поэтому попроси Claude сохранять точечный scope и не использовать `git clean`, `git reset --hard` или массовый `git restore`.

Дополнительные инструкции Anthropic: [проектная память CLAUDE.md](https://docs.anthropic.com/en/docs/claude-code/memory), [установка и вход](https://docs.anthropic.com/en/docs/claude-code/getting-started), [CLI](https://docs.anthropic.com/en/docs/claude-code/cli-usage).
