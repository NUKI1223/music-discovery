# Прямые страницы альбомов — 2026-11-06

Карточки больше не создают поисковые ссылки Spotify, YouTube Music и
Bandcamp из имени исполнителя и названия альбома. Вместо этого раздел
«Открыть альбом» содержит только прямые ссылки из каталога либо результат
сопоставления с альбомом в Apple Music/Deezer. Ссылки на AOTY, RYM и
MusicBrainz остаются отдельными источниками сведений.

Если прямой ссылки нет, карточка сообщает: «Прямая ссылка на площадку пока
не найдена». Во время запроса — «Ищем прямую ссылку на альбом…».
Отсутствие ссылки не утверждает отсутствие релиза на площадках.
Найденная страница также не гарантирует доступность воспроизведения во
всех регионах или сохранность релиза после даты проверки.

## Правила

- Общий frontend-классификатор проверяет тип страницы для ссылок каталога
  и ответа API. Поиск, страницы исполнителей и треков не становятся
  кнопками прослушивания и не перемещаются в блок источников.
- Прямые страницы Spotify остаются доступными, когда ссылка есть в
  каталоге. Поисковая ссылка не подменяет её. Новый поиск Spotify через
  неофициальные API в этой задаче не добавляется.
- Apple Music/Deezer: точное нормализованное название и полный кредит
  исполнителя; разные тома/издания не смешиваются. Результат для сольного
  исполнителя не считается совпадением с совместным релизом.
- Если одинаковые названия указывают на несколько разных альбомных страниц,
  результат считается неоднозначным. Первый результат не выбирается
  автоматически. Названия сами по себе не решают все случаи омонимии.
- Альбомная ссылка пригодна и без обложки. И наоборот: найденная обложка
  AOTY больше не прекращает поиск страницы для прослушивания. AOTY сохраняет
  приоритет как источник обложки, а магазин может дать прямую ссылку.
- Старая версия кэша не используется для новых результатов; ключ
  `album-pages-v3`. Кэш переживает перезапуск, прежний лимит запросов и
  паузы при блокировке AOTY сохраняются. Поиск прекращается после первого
  однозначного результата магазина; это не полный список площадок релиза.

Схема API, каталог, рекомендации, пользовательские оценки и история не
изменяются. Новое отображение применяется и к карточкам старых диалогов.

## Проверки

Backend: совпадение названия/полного кредита, запрет неальбомных URL,
неоднозначность, наличие ссылки без обложки, обложка AOTY одновременно
с магазином, отсутствие результатов, старый кэш и сохранение нового кэша.
Браузер: кнопка ведёт на конкретную страницу; карточка без совпадений
показывает пустое состояние и сохраняет AOTY; поисковых ссылок нет даже
при их наличии в старых данных или ответе API.

Отчёты: `artifacts/evals/direct-album-links-20261106/`.
Проверки сетевых ответов используют mock-данные; они не заявляют проверку
живого наличия всех альбомов каталога. Платные вызовы не выполнялись.

Проверка 2026-11-06: 777 Python-тестов и 8 offline-сценариев, 32 браузерных
теста прошли. Сервер перезапущен с резервной копией; отпечатки пользовательской
истории до/после совпали. Вызовов платного провайдера не было.
